# GlobtimPlots.jl

Makie-based figures for the [Globtim](https://github.com/gescholt/Globtim.jl) global
optimization pipeline: level sets of a polynomial approximant with its critical points,
Morse (Hessian) diagnostics, degree sweeps, adaptive-subdivision partitions and
experiment-campaign summaries.

GlobtimPlots sits at the visualization layer of the Globtim ecosystem and contains no
algorithms or statistics of its own:

```
Globtim → GlobtimPostProcessing → GlobtimPlots
(compute)   (results, statistics)  (figures)
```

## Installation

Requires Julia 1.12 or newer.

```julia
using Pkg
Pkg.add("GlobtimPlots")            # once the registration in General completes;
                                   # until then: Pkg.add(url = "https://github.com/gescholt/GlobtimPlots.jl")
Pkg.add(["HomotopyContinuation", "DynamicPolynomials"])   # Globtim's critical-point solver
```

`Globtim` and `GlobtimPostProcessing` are dependencies and come in automatically.
`CairoMakie` is re-exported, so `using GlobtimPlots` alone gives a working static backend.
Add `GLMakie` for interactive windows (see [Backends](api.md#Backends)).

## Quick start

Approximate a test function with Globtim, solve for the critical points of the
approximant, and draw the level set with those points overlaid:

```julia
using Globtim, GlobtimPlots
using DynamicPolynomials: @polyvar
import HomotopyContinuation  # enables Globtim's :hc solver (`import`: it also exports a `save`)

# 1. Fit a degree-6 Chebyshev polynomial to the six-hump camel function on [-5, 5]^2
f  = camel
TR = TestInput(f; dim = 2, center = [0.0, 0.0], sample_range = 5.0, GN = 200)
pol = Constructor(TR, 6; basis = :chebyshev, precision = RationalPrecision)

# 2. Critical points of the approximant, refined on f and classified by their Hessian
@polyvar x[1:2]
sols = solve_polynomial_system(x, 2, 6, pol.coeffs;
    basis = pol.basis, precision = pol.precision, normalized = pol.normalized)
df_cp = process_crit_pts(sols, f, TR)
df_cp, df_min = analyze_critical_points(f, df_cp, TR; tol_dist = 0.01, verbose = false)

# 3. Level set of the approximant with the critical points overlaid
fig = cairo_plot_polyapprox_levelset(
    adapt_polynomial_data(pol), adapt_problem_input(TR), df_cp, df_min;
    chebyshev_levels = true, title = "Six-hump camel — Chebyshev degree 6",
)
save("camel_levelset.png", fig)
```

The package README continues this session with the Morse diagnostics, a degree sweep,
an adaptive subdivision and campaign summaries; those snippets are executed by the test
suite, so they run as written. The [API Reference](api.md) lists every function with its
keyword arguments.
